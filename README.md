# Slides

Archive of slide decks from talks & pitches I've given over the years.

Most decks are written in [Marp](https://marp.app/) (Markdown → HTML/PDF), so the
source for those lives in `index.md` inside each folder, with generated `index.html`
and/or a `.pdf` alongside. A few older decks are kept as exported PDFs only.
